담당 시스템
1. 자산운용시스템(FORMS)
2. PMS(부보기관 보험산정표등록)
3. DBAS(디지털예산시스템)
4. IFRS(국제회계시스템)
5. 경영정보시스템
6. ICPRO(내부통제시스템)

각 시스템마다 툴과 기술이 다름
1. 자산운용시스템(FORMS)
    : 파워빌더를 이용해서 화면 개발
      쉘 파일로 외부와 연동하여 자료 받고 자바로 파일을 읽어서 디비에 넣음
      데이터가 너무 많아서 힘듬
2. PMS(부보기관 보험산정표등록)
    : 그냥 웹 포털
      관리자 페이지는 예산시스템에 붙어 있음
      부보기관관리를 예산시스템에서 함
3. DBAS(디지털예산시스템)
    : trustform
      예산 시스템 인데 기재부 디브레인에서 1년에 한번 예산 세목을 받아옴
4. IFRS(국제회계시스템)
    : trustform
      말데로 국제회계시스템
5. 경영정보시스템
    : trustform
      운영 기간이 짧아서 잘 모르곘음
6. ICPRO(내부통제시스템)
    : trustform
      내부 조직간에 프로젝트 진행 머 그런거 같음
